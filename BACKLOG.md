# tgvault — беклог

Переписывание tg-import на Go. Ядро (спайк) пройдено; ниже — что решено, что сделано, что осталось и открытые вопросы.

## Решённое (архитектура)

- [x] Язык: **Go**, чистый (без Python), кросс-платформа, один бинарник.
- [x] MTProto: `gotd/td`; повторный логин — ок.
- [x] Транскрибация: **whisper.cpp** (локально, `tiny`/`base` дефолт), отдельным модулем. Gemini заблокирован по региону (нужен прокси — опционально).
- [x] Хранилище: плоско, внутри проекта — `docs/telegram_chats/<chat>_<topic>/` (один уровень).
- [x] Конфиг v2 `.tg-import.json`: проект + реестр записей «чат+топик» (`id`, `access_hash`, `kind`, `slug`, `default`) + справочник `note`/`when`/`write_to` (только чтение).
- [x] `init`: интерактивный мастер — вопросы, резолв чатов, галочки, **поиск `/`**.
- [x] Конкурентность: блокирующий `flock` на сессию — второй процесс **ждёт**, а не падает.
- [x] Сессия глобальная (`~/.config/tgvault/session.json`); `.env` глобальный + проектный.
- [x] Медиа: качаем, привязано к сообщению; если текста нет — `(без текста)` в той же секции.
- [x] Формат лога и дедуп по `<!-- msg:ID -->` — как в оригинале.

## Сделано (спайк, проверено рантаймом)

- [x] Логин + сессия.
- [x] Список диалогов / поиск чата.
- [x] Форум-топики (список) + чтение топика (`getReplies`).
- [x] Скачивание голосового.
- [x] Локальная транскрибация whisper.cpp `tiny`.
- [x] Блокирующий лок сессии.
- [x] **Секреты отдельно от кода**: `{{secret:NAME}}` в `.env`, значения — в
  `~/.secrets/tgvault/<NAME>` (0600), команда `tgvault secret set/ls/ref/rm/check`,
  подстановка в окружение при старте, маскировка значений в логах и `-h`. `setup`
  пишет ключи в хранилище, в `.env` — ссылки. Одно значение под несколькими именами
  в логах даёт одно каноническое имя. Проверено рантаймом + 9 unit-тестов.
- [x] **Самообновление** `tgvault update`: тянет последний релиз с GitHub и
  атомарно заменяет бинарь на месте (повторно `install.sh` не нужен); `-check` —
  только проверка. Версия в бинарь — через `ldflags`. Раз в сутки команды с
  Telegram напоминают о новом релизе (`TGVAULT_NO_UPDATE_CHECK=1` отключает).
  Проверено вживую (`update -check` увидел v0.1.3) + тесты `internal/update`.

## Осталось (беклог)

- [x] **Команда `import`** по конфигу: импорт дефолтных/выбранных записей. Проверено на «Mind».
- [x] **Watermark** (state-файл `<slug>/.tg-state.json`, поле `last_id`): тянуть только новое. Решение: state-файл.
- [x] **Правки/удаления**: по умолчанию не собираем; `--full` — полный пересбор. Точечный режим (карта `edit_date`) — позже.
- [x] Флаги импорта: `--from/--to`, `--all`, `--entry`, `--full`.
- [x] Модель по умолчанию: `base` (качество приемлемо для LLM). `tiny` — лёгкая опция.
- [x] Справочник `note`/`when`/`write_to`: спрашивается в `init` (можно пропустить).
- [x] **Миграция v1→v2**: команда `migrate` — проверена живьём (бэкап `.v1.bak`, перенос папки, v2-конфиг с `access_hash`).
- [x] Имена папок: `<chat>` или `<chat>_<topic>` (одиночный `_`).
- [x] Импорт устойчив к старому формату (нормализует `-100…`/`group`, добивает `access_hash`).
- [x] Reply-ссылки: подтягивается превью (дозагрузка сообщений), висячих `msg:N` больше нет.
- [x] **Инструкции для агентов** (SKILL.md): написан `SKILL.md` в репо (жёсткие правила «не ставить, не изобретать»). Установка в скилл-каталоги агентов — при упаковке.
- [x] **Установочный мастер** (`tgvault setup`): проверка deps, выбор моделей (мультивыбор), скачивание в `~/.local/share/tgvault/models`, выбор дефолтной, ключи, запись глобального `.env`. GigaAM/vosk пока не в мастере (нужны их либы).
- [x] **Упаковка**: `install.sh` (однострочник → `~/.local/bin`), `Makefile` (`make cross`, 5 целей), `.goreleaser.yaml` + GitHub Actions на тег. Крест-компиляция проверена (Mach-O arm64 с Linux). Репо-плейсхолдер `Fugguri/tgvault`.
- [x] `setup` спрашивает TG api_id/api_hash и пишет всё в глобальный `.env`; умеет собрать `whisper-cli` из исходников (git+cmake) и скачать модели. Есть неинтерактивный режим (`-unattended -models ... -api-id ... -api-hash ...`). Проверено живьём.
- [x] `whisper-cli` доставка: `setup` собирает whisper.cpp из исходников (whisper.cpp не публикует бинари — проверено). Релизный бандл — опционально позже.
- [x] Портированы `send`/`edit`/`delete` (текст, файлы, reply/topic, dry-run по умолчанию, резолв по alias/имени/id) и `bot` (клик-тест: send/click/expect/expect-doc/sleep, dry-run, защита от необратимых кнопок). Dry-run проверен; реальные отправки не гонялись.
- [x] Оптимизация ASR: `whisper-server` (модель грузится один раз на импорт, HTTP `/inference`), fallback на `whisper-cli`. Проверено: 314 сообщений + 3 голосовых = 53 c.
- [x] Внутренняя накапливающаяся очередь транскрибации: текст пишется сразу с плейсхолдером `🎤 (транскрибируется…)`, воркер распознаёт и обновляет секцию на месте (per-file mutex, атомарная запись). Проверено: 0 плейсхолдеров, 3 транскрипта.
- [x] Команда `list` — компактная сводка записей проекта (где искать чат), без чтения всего конфига.
- [x] Мелочи закрыты: `send` файла печатает `msg_id`; мегагруппы отображаются как `group` (label отдельно от storage-`kind`); `import`/`migrate` проверяют конфиг **до** коннекта к Telegram.
- [ ] **Будущее:** отложенная/фоновая транскрибация с уведомлением (detached-воркер + state + `status`; desktop/Telegram-пинг; пуш агенту через плагин). Ядро остаётся агент-независимым, пуш — опциональный адаптер.
- [ ] **Холодный старт / тёплая модель:** держать в памяти маленькую модель (демон `serve`), большую — включать опцией в конфиге. Убирает загрузку модели на каждый запуск.
- [x] Облачная транскрибация (genai SDK) удалена — бинарь 68→26 МБ. Облако при нужде — на голом `net/http` (регион-блок в RU).
- [ ] SQLite-зеркало (опционально) + `edit_date`.
- [ ] Демон `serve` (Unix-сокет) — для конкуренции и переиспользования соединения/модели (позже).
- [x] README + лицензия (MIT). Публикация/релизы/установка глобально — по решению пользователя отложены.
- [x] Опубликовано: репо https://github.com/Fugguri/tgvault, релиз v0.1.0 (linux/darwin × amd64/arm64), install.sh проверен end-to-end.

## Модели транскрибации (все — на выбор пользователя, мультивыбор)

**whisper.cpp (GGML, cgo):**
- [ ] `tiny` (~75 МБ) — самый лёгкий, качество на русском слабое.
- [x] `base` (~142 МБ) — **дефолт** (качество приемлемо для LLM).
- [ ] `small` (~466 МБ)
- [ ] `medium` (~1.5 ГБ)
- [ ] `large-v3` (~3 ГБ) — точнее, медленно на CPU.

**GigaAM (sherpa-onnx, cgo+onnxruntime):**
- [ ] `gigaam-v2-ctc-russian` / `gigaam-v3` — SOTA русский ASR (~320 МБ int8, с пунктуацией). Проверено: sherpa-onnx Go-биндинги существуют (`k2-fsa/sherpa-onnx-go`).

**Vosk (libvosk, cgo):**
- [ ] `vosk-model-small-ru` — лёгкий русский, без пунктуации (модель уже есть в voice-pc).

**Облако (нужен прокси в RU):**
- [~] Gemini `2.5-flash` — удалён (регион-блок + вес SDK). Вернуть на голом HTTP при нужде.
