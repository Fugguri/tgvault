# tgvault — беклог

Переписывание tg-import на Go. Ядро (спайк) пройдено; ниже — что решено, что сделано, что осталось и открытые вопросы.

## Решённое (архитектура)

- [x] Язык: **Go**, чистый (без Python), кросс-платформа, один бинарник.
- [x] MTProto: `gotd/td`; повторный логин — ок.
- [x] Транскрибация: **whisper.cpp** (локально, `tiny`/`base` дефолт), отдельным модулем. Gemini заблокирован по региону (нужен прокси — опционально).
- [x] Хранилище: плоско, внутри проекта — `docs/telegram_chats/<chat>_<topic>/` (один уровень).
- [x] Конфиг v2 `.tg-import.json`: проект + реестр записей «чат+топик» (`id`, `access_hash`, `kind`, `slug`, `default`) + справочник `note`/`when`/`write_to` (только чтение).
- [x] `init`: интерактивный мастер — вопросы, резолв чатов, галочки, **поиск `/`**.
- [x] Конкурентность: блокирующий `flock` на сессию — второй процесс **ждёт**, а не падает.
- [x] Сессия глобальная (`~/.config/tgvault/session.json`); `.env` глобальный + проектный.
- [x] Медиа: качаем, привязано к сообщению; если текста нет — `(без текста)` в той же секции.
- [x] Формат лога и дедуп по `<!-- msg:ID -->` — как в оригинале.

## Сделано (спайк, проверено рантаймом)

- [x] Логин + сессия.
- [x] Список диалогов / поиск чата.
- [x] Форум-топики (список) + чтение топика (`getReplies`).
- [x] Скачивание голосового.
- [x] Локальная транскрибация whisper.cpp `tiny`.
- [x] Блокирующий лок сессии.
- [x] **Секреты отдельно от кода**: `{{secret:NAME}}` в `.env`, значения — в
  `~/.secrets/tgvault/<NAME>` (0600), команда `tgvault secret set/ls/ref/rm/check`,
  подстановка в окружение при старте, маскировка значений в логах и `-h`. `setup`
  пишет ключи в хранилище, в `.env` — ссылки. Одно значение под несколькими именами
  в логах даёт одно каноническое имя. Проверено рантаймом + 9 unit-тестов.
  **Отменено в v0.1.5:** `setup` пишет значения прямо в `.env` (хранилище `~/.secrets`
  для этого не требуется); `secret` остался опциональным слоем поверх.
- [x] **Самообновление** `tgvault update`: тянет последний релиз с GitHub и
  атомарно заменяет бинарь на месте (повторно `install.sh` не нужен); `-check` —
  только проверка. Версия в бинарь — через `ldflags`. Раз в сутки команды с
  Telegram напоминают о новом релизе (`TGVAULT_NO_UPDATE_CHECK=1` отключает).
  Проверено вживую (`update -check` увидел v0.1.3) + тесты `internal/update`.
- [x] **Секреты из чатов**: при `import` токены/ключи в переписке заменяются на
  `{{secret:<NAME>}}`, значения — в `docs/telegram_chats/<slug>/.secrets.json` (0600,
  gitignore). Детект по паттернам (tg-токен, `sk-`, `ghp_`, `AIza`, `AKIA`, `xox`,
  JWT, privat key, `api_key/token/password=…`), имя детерминировано от значения
  (повтор → одно имя). Флаг `-no-secrets`; чтение — `tgvault secret chat <slug> [NAME]`.
  Проверено тестами `internal/redact` и `importer`.

## Осталось (беклог)

- [x] **Команда `import`** по конфигу: импорт дефолтных/выбранных записей. Проверено на «Mind».
- [x] **Watermark** (state-файл `<slug>/.tg-state.json`, поле `last_id`): тянуть только новое. Решение: state-файл.
- [x] **Правки/удаления**: по умолчанию не собираем; `--full` — полный пересбор. Точечный режим (карта `edit_date`) — позже.
- [x] Флаги импорта: `--from/--to`, `--all`, `--entry`, `--full`.
- [x] Модель по умолчанию: `base` (качество приемлемо для LLM). `tiny` — лёгкая опция.
- [x] Справочник `note`/`when`/`write_to`: спрашивается в `init` (можно пропустить).
- [x] **Миграция v1→v2**: команда `migrate` — проверена живьём (бэкап `.v1.bak`, перенос папки, v2-конфиг с `access_hash`).
- [x] Имена папок: `<chat>` или `<chat>_<topic>` (одиночный `_`).
- [x] Импорт устойчив к старому формату (нормализует `-100…`/`group`, добивает `access_hash`).
- [x] Reply-ссылки: подтягивается превью (дозагрузка сообщений), висячих `msg:N` больше нет.
- [x] **Инструкции для агентов** (SKILL.md): написан `SKILL.md` в репо (жёсткие правила «не ставить, не изобретать»). Установка в скилл-каталоги агентов — при упаковке.
- [x] **Установочный мастер** (`tgvault setup`): проверка deps, выбор моделей (мультивыбор), скачивание в `~/.local/share/tgvault/models`, выбор дефолтной, ключи, запись глобального `.env`. GigaAM/vosk пока не в мастере (нужны их либы).
- [x] **Упаковка**: `install.sh` (однострочник → `~/.local/bin`), `Makefile` (`make build` собирает whisper.cpp + бинарь), GitHub Actions на тег (нативная матрица linux/darwin × amd64/arm64 — cgo не кросс-компилируется). Крест-компиляция Mach-O с Linux больше не используется. Репо `Fugguri/tgvault`.
- [x] `setup` спрашивает TG api_id/api_hash и пишет всё в глобальный `.env`; умеет собрать `whisper-cli` из исходников (git+cmake) и скачать модели. Есть неинтерактивный режим (`-unattended -models ... -api-id ... -api-hash ...`). Проверено живьём. **Отменено в v0.2.0:** сборка `whisper-cli` убрана, `setup` только качает модели.
- [x] `whisper-cli` доставка: `setup` собирает whisper.cpp из исходников (whisper.cpp не публикует бинари — проверено). Релизный бандл — опционально позже. **Отменено в v0.2.0:** whisper.cpp вшит в бинарь через cgo, внешний `whisper-cli` не нужен.
- [x] Портированы `send`/`edit`/`delete` (текст, файлы, reply/topic, dry-run по умолчанию, резолв по alias/имени/id) и `bot` (клик-тест: send/click/expect/expect-doc/sleep, dry-run, защита от необратимых кнопок). Dry-run проверен; реальные отправки не гонялись.
- [x] **Управление чатами `manage`** (dry-run по умолчанию, реально — `-send`): `create` (группа/супергруппа/канал, `-forum`), `topic`, `forward` (`-msg`/`-last`, `-dest-topic`), `invite`, `rights` (пресеты + точечные права + rank + revoke), `kick` (`-ban`/`-days`), `delete`. Резолв людей — `@login`/`id`/`+phone`. Проверены dry-run'ы, сборка и живые действия на тестовой супергруппе/канале/группе.
- [x] **Согласование исходящих действий** (`internal/approve` + `internal/cli/gate.go`): `send`/`manage -send`/`bot -go` выполняются только с одноразовым согласованием, привязанным к хэшу содержимого; `tgvault approve <id>` (только TTY, TTL) и `tgvault pending`. Проверено вживую (TTY через pty) + unit-тесты. **Отменено в v0.4.1:** `approve <id> -y` работает без терминала — агент согласует сам после «да» пользователя; TTY нужен только в строгом режиме (`TGVAULT_APPROVAL=strict`).
- [x] Оптимизация ASR: `whisper-server` (модель грузится один раз на импорт, HTTP `/inference`), fallback на `whisper-cli`. Проверено: 314 сообщений + 3 голосовых = 53 c. **Отменено в v0.2.0:** `whisper-server`/`whisper-cli` удалены, whisper.cpp вшит в бинарь через cgo.
- [x] **Отвязались от `whisper-cli`:** whisper.cpp вшит в бинарь через cgo (`internal/transcribe/native.go`), модель `ggml-*.bin` открывается в процессе и грузится один раз; ffmpeg декодирует ogg/opus в PCM. Внешний бинарь/сервер больше не нужен, `setup` только качает модели. `make build` собирает статический whisper.cpp (`third_party/whisper.cpp/build_go`). Проверено живьём: `voice_6085.ogg` → русский текст.
- [x] Внутренняя накапливающаяся очередь транскрибации: текст пишется сразу с плейсхолдером `🎤 (транскрибируется…)`, воркер распознаёт и обновляет секцию на месте (per-file mutex, атомарная запись). Проверено: 0 плейсхолдеров, 3 транскрипта.
- [x] Команда `list` — компактная сводка записей проекта (где искать чат), без чтения всего конфига.
- [x] **Команда `view`** — быстрый просмотр сообщений за период **без импорта**: читает историю
  напрямую из Telegram, печатает текстом (логи не пишет, медиа не качает). Цель — `-entry`/`-chat`/
  `-id`/`-alias` (+`-topic`); период — `-from/-to` (по умолчанию 7 дней) или `-last`; лимиты —
  `-max-len`/`-max-msgs`; медиа — пометки, `-media` (кэш + пути), `-transcribe` (голосовые).
- [x] Мелочи закрыты: `send` файла печатает `msg_id`; мегагруппы отображаются как `group` (label отдельно от storage-`kind`); `import`/`migrate` проверяют конфиг **до** коннекта к Telegram.

## Ревью v0.5.1 — окно импорта (закрыто 1–5 в v0.5.2, 2026-10-14)

Ревью коммита `cbf7faa` («окно 30 дней»), находки перепроверены по коду. Порядок — по
убыванию цены; п. 2–3 — молчаливая потеря переписки, невосстановимая штатными флагами.

- [x] **Окно применяется на каждом проходе, а не только на первом.** Закрыто: границы
  считаются на каждую запись отдельно (`cli.Import` → `importer.ResolveRange` с её
  watermark), окно получает только запись без состояния. Тест
  `TestResolveRangeNoWindowWhenStateExists`.
- [x] **`-all-history` при существующем watermark не делает ничего.** Закрыто:
  `Range.IgnoreWatermark` сбрасывает `MinID` в 0, пагинация идёт до конца. Тест
  `TestResolveRangeAllHistoryIgnoresWatermark`.
- [x] **Аварийный выход сломан.** Закрыто как следствие: `-all-history` теперь реально
  тянет историю заново, то есть дыру ниже watermark есть чем заткнуть без `-full`.
- [x] **`-to` без `-from` даёт ноль сообщений.** Закрыто: окно не применяется при
  заданной верхней границе. Тест `TestResolveRangeToWithoutFrom`.
- [x] **Опечатка в `-from` тихо превращается в окно 30 дней.** Закрыто: `ParseDate`
  возвращает ошибку, `cli.ParseDate` её не глотает, `main.go` разбирает `-from`/`-to`
  до коннекта и падает с внятным текстом; даты из конфига проверяются в `cli.Import`
  до записи на диск. Тесты `TestResolveRangeMalformedFrom`, `TestParseDateMalformed`.
  Проверено рантаймом: `import -from 2026-1-5` → `ошибка: -from: дата "2026-1-5":
  нужен формат YYYY-MM-DD`, коннекта нет.
- [ ] **Политика окна — в CLI, а не в importer.** Частично: вычисление уехало в
  `importer.ResolveRange`, но поля `Unbounded` в `Options` так и нет, а комментарий
  `Options.From` («нулевое = без границы») всё ещё неточен. Осталось решить, нужен ли
  `Unbounded` в `Options` или хватает `MinID`/`Rebuild`.
- [ ] **`-full` выведен из-под окна**, а SKILL.md:74/77 и подсказка зовут его как «вся
  история» — рекомендуют путь, ловящий FLOOD_WAIT. Решение не принято: оставить
  `-full` оконным или честно описать его как «вся история, медленно».

## Модели транскрибации

Отметка здесь — **скачана ли модель локально**, а не «сделано ли». Это не беклог:
whisper-модели давно поддержаны — `tgvault setup` даёт мультивыбор и качает их в
`~/.local/share/tgvault/models` (неинтерактивно: `-models tiny,base,…`). Список —
`internal/cli/setup.go:22`, источник — `huggingface.co/ggerganov/whisper.cpp`.

**whisper.cpp (GGML, cgo) — доступны пользователю:**

- [ ] `tiny` (~75 МБ) — самый лёгкий, качество на русском слабое.
- [x] `base` (~142 МБ) — **дефолт**, скачана.
- [ ] `small` (~466 МБ)
- [ ] `medium` (~1.5 ГБ)
- [ ] `large-v3` (~3 ГБ) — точнее, медленно на CPU.

**Не реализовано — вот это задачи (нужны cgo-биндинги):**

- [ ] **GigaAM** (sherpa-onnx, cgo+onnxruntime): `gigaam-v2-ctc-russian` / `gigaam-v3` —
  SOTA русский ASR (~320 МБ int8, с пунктуацией). Проверено: Go-биндинги существуют
  (`k2-fsa/sherpa-onnx-go`).
- [ ] **Vosk** (libvosk, cgo): `vosk-model-small-ru` — лёгкий русский, без пунктуации
  (файл модели уже есть в voice-pc — качать не придётся).

**Облако (нужен прокси в RU):**
- [~] Gemini `2.5-flash` — удалён (регион-блок + вес SDK). Вернуть на голом HTTP при нужде.
